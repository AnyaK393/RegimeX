RegimeX - how to run on a new PC
================================
1. Install Python 3.11 or 3.12.
2. Open a terminal IN THIS FOLDER (the one containing README.md).
3. (Recommended) create a virtual environment:
     python -m venv .venv
     Windows:      .venv\Scripts\activate
     macOS/Linux:  source .venv/bin/activate
4. Install dependencies:
     pip install -r requirements.txt
5. Reproduce the results with the models and data already included:
     python src/evaluate_pooled.py                    # v1 pooled evaluation
     python src/evaluate_v3.py --split test           # v3 (gamma 3.0)
     python src/evaluate_v3.py --gamma-base 0.75 --split test
     python src/explain_shap_v3.py --kind adaptive    # SHAP
     python src/test_exposure_env.py                  # environment tests
Results and figures are written to results/.  Read docs/REPORT.md first.
Retraining (about 35-40 min per batch on CPU): see docs/PHASE2_RESULTS.md, section 11.
